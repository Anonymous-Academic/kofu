DMD EVI-DMS final split v1
===========================

Decision:
  Use the true 5-fold subject-disjoint split generated by audit v2.

Use:
  Protocol A:
    Train/evaluate only the 11 canonical classes.
    Exclude unclassified/change_gear/standstill_or_waiting from closed-set classification.

  Protocol B:
    Use the same subject partitions.
    Known = 11 canonical classes.
    Non-canonical unknown = unclassified/change_gear/standstill_or_waiting.
    Because change_gear and standstill_or_waiting are extremely rare, class-specific rare-case analysis should be pooled across folds.

  Protocol C:
    Use the same subject partitions, but additionally hold out action groups from the 11 canonical classes.

  Protocol D:
    Use the same subject partitions and protocol-A main11 labels; apply missing-view/evidence corruption only at evaluation time unless explicitly training a robustness variant.

Guarantee:
  Every fold assigns all 14 subjects and all 49 recordings to exactly one of train/val/test.
  No recording is dropped by this split.
  No interval is dropped by the assignment file.
  Protocol-specific exclusions are explicit flags, not silent omissions.
